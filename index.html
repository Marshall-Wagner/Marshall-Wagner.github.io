Enterprise 802.1X / RADIUS Authentication

Personal lab project building enterprise wireless authentication on both the Microsoft and open-source RADIUS stacks. Windows side: stood up Windows Server 2025 with Active Directory, AD Certificate Services (Enterprise Root CA), and Network Policy Server (NPS) as the RADIUS server; issued the NPS server certificate from the internal CA, configured PEAP-MSCHAPv2 against Active Directory, and authenticated real wireless clients (phone and laptop) through a WPA2-Enterprise (AES) access point - validated end-to-end from a Linux client with eapol_test before connecting real devices, with a per-client random RADIUS shared secret. The 802.1X model authenticates each user with their own AD credentials, giving per-user accountability and audit logging instead of a shared Wi-Fi password. Linux side: FreeRADIUS with a MariaDB (MySQL-compatible) backend. Covers both the Microsoft (NPS/AD) and open-source (FreeRADIUS) 802.1X stacks - the same enterprise wireless authentication that production networks run.

Facility AV Broadcast Migration - Satellite to Terrestrial ATSC

Migrated facility AV from Dish Network satellite to terrestrial ATSC 1.0/3.0 OTA reception. Outdoor VHF/UHF antenna feeds an Antronix powered splitter (built-in amplification, high-pass filter rejecting sub-TV-band noise, multi-port distribution to 5 endpoints). Replaced legacy RG59 with quad-shielded RG6 (solid copper core) - quad shielding rejects EMI/RFI from manufacturing equipment, solid copper preserves DC pass-through powering the splitter via coax. Antronix splitter powered via UPS-fed coaxial injector - amplification stays online through power flickers and brownouts. Doubled coverage from 2 to 5 TVs while eliminating ~$1,320/year in subscription + rebroadcast fees.
